AWS Credentials

Stored to ~/.aws/credentials inside the container. If you mounted ~/.aws/ from your host, this overwrites it.

Azure Credentials

Service Principal recommended (admin user with MFA can't login in a headless container). Create one with az ad sp create-for-rbac --role Owner --scopes /subscriptions/<sub> on your local machine, then paste the four values below.

If provided, we'll compare this against az account show and warn on mismatch.
